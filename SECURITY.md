# Security policy

Please report suspected vulnerabilities privately to **you@example.com** (replace before publishing)
rather than opening a public issue. Include a description, reproduction steps, and the affected version.

Scope notes: this library produces decisions from signed, verified tables. Issues of particular interest are
signature/hash bypasses, ways to make a verified table behave differently from its approved decisions,
and ways untrusted text can influence feature extraction beyond the closed vocabulary.
